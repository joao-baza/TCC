\begin{frame}{Problema e motivação}
  \begin{itemize}
    \item Ferramentas fortes de simulação existem, mas nem sempre são acessíveis no ensino.
    \item O aprendizado didático costuma ficar separado da execução computacional real.
    \item O projeto busca uma base aberta para ensino de operações unitárias.
  \end{itemize}
\end{frame}

\begin{frame}{Por que isso é uma monografia}
  \begin{itemize}
    \item Há problema, objetivos, desenvolvimento, validação e conclusões.
    \item O produto aparece como artefato de pesquisa e não como pitch isolado.
    \item A inovação é sustentada por evidência técnica e acadêmica.
  \end{itemize}
\end{frame}
